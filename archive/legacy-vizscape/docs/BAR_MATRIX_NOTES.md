# bar-matrix 3D 透视矩阵说明

> 视觉与交互层说明。数据解析复用 bar-basic 的 csv/json/xlsx 链路。

## 定位

不是“每根柱单独加阴影的 3D 柱状图”，而是**一个共享地板的场景**：

- X = 分类
- Y = 系列
- Z = 数值高度
- 多系列共处同一透视空间，便于比较整体形态与极值位置

## 支持

- 10 种配色：Signal / 朱砂 / 铜绿 / 蓝图 / 水墨 / 单色 / 落日 / 敦煌 / 极光 / 莫兰迪
- ▦ 浓淡编码：开启后按数值比例调节柱体明度，低值浅、高值饱和，数值大小在颜色上也可读
- 景深雾化：远离视点的柱体自动向背景色淡化，增强前后层次
- 柔和接触阴影：柱底为径向渐变的椭圆软阴影，不再是平涂暗面
- 3 种截面：方柱 / 圆柱 / 八棱柱
- 3 种棱边（仅方柱）：锐边 / 圆棱 / 切棱；切到圆柱或八棱时棱边开关自动置灰
- 4 种顶帽：平顶 / 穹顶（收分台）/ 尖顶（锥顶）/ 凹槽（下沉刻槽）
- 侧面光照随方位角连续变化：圆柱/八棱的每个小面按朝向独立明暗
- 归一模式：全局 / 按列
- 排序：按值 / 按标签 / 原始
- 高度缩放：150–400
- 顶面数值、坐标轴开关
- 拖拽旋转、滚轮缩放、自动旋转、重置视角
- 悬浮命中整根柱：占总、占列、占行
- 数据识别报告：缺失、非法、负值、重复组合
- 图例显隐；隐藏 series 后重新计算归一与布局

## 负值约束

3D 矩阵的地板在 z=0，负值柱没有地面以下空间，强行画会变成“贴地小柱”从而误导。

因此：

- 任何数值 < 0：停用 3D 绘制
- 画布显示明确空态：`3D 透视矩阵不支持负值`
- 数据识别报告标红负值数量
- 推荐替代：分组 / 堆叠 / 瀑布图

## 可访问性

- 图例按钮带 `aria-pressed`
- 工具按钮切换后同步 `aria-pressed`
- Canvas 不是唯一信息载体：下方表格保留完整数值
- `:focus-visible` 使用当前调色板强调色
- 负值空态写入 `#detail`，键盘/读屏可读

## 与 bar-basic 的边界

- 共享输入解析与质量报告
- 不共享渲染器：bar-matrix 是自己的一套投影/拾取
- 视觉风格（主题、配色、卡片、质量报告样式）在模板层维护
- 投影数学、归一、排序、拾取算法在 vizlib/charts 模块维护；模板只通过公开配置消费
