# Virta 桑基图（sankey-basic）输入契约

桑基图回答**「流量从哪里来、到哪里去」**：多对多路径流动，是漏斗的通用化。

## 1. 列契约

| 列 | 别名 | 说明 |
|---|---|---|
| **source** | `source` / `from` / `src` / `源` / `来源` / `起点` / `上游` | 必填 |
| **target** | `target` / `to` / `dst` / `目标` / `去向` / `终点` / `下游` | 必填 |
| **value** | 全量数值别名 | 必填，必须为正数 |

```csv
source,target,value
搜索引擎,首页,6800
首页,产品详情,5200
```

## 2. 数据规则

- **DAG 校验**：桑基图要求有向无环。检测到循环依赖时，自动剔除环上**流量最小的边**并在识别报告中列出（如 `C→A`）。
- 重复 `(source, target)` 边**求和合并**；
- `source == target` 自环剔除；
- 数值缺失 / 非正数剔除；
- 所有剔除与合并都计入**数据识别报告**。

## 3. 布局与交互

- **最长路径分层**：入度为 0 的是源节点，每层深度 = 上游最深 +1；
- **重心法排序**：4 遍正反 sweep 减少流带交叉；
- 流带宽度 ∝ 流量，颜色 = 源节点色 → 目标节点色渐变（可关）；
- 悬停**节点**：高亮其整条上下游链路，明细行列出每项流入/流出；
- 悬停**流带**：单条流量 + 占源节点流出比；
- **节点可上下拖拽**微调布局，流带自动跟随；
- 标签三态：名称+值 / 仅名称 / 隐藏；舒适/紧凑密度。

## 4. 命令
