# 三维散点图 输入契约

> 定位：在二维散点（x/y 关系）基础上多一个维度——**Z 轴（深度）**，位置由三个数值共同决定，颜色=分组，气泡大小可再编码第 4 维。拖拽旋转视角后判读位置关系。

## 适用场景

- 投放(投入) × 转化(产出) × 利润(结果)，按渠道分色、客单价作气泡
- 价格 × 销量 × 库存，按品类分色
- 三项体检指标同时看（身高 × 体重 × 血压）

不适合：

- 只有 x/y 两维关系 → 普通散点（`--view scatter`）
- 看随时间变化 → 折线（`--view line`）
- 看份额构成 → 占比/树状图（`--view pie`/`--view treemap`）

## 输入 schema

| 列 | 必需 | 别名 | 说明 |
|---|---|---|---|
| X | 是 | x/横轴/自变量/投入/成本 | 水平轴 |
| Y | 是 | y/纵轴/因变量/转化/收益 | 纵轴 |
| Z | 是 | z/竖轴/高度/深度/利润/评分/数量/金额/销量/权重 | 深度轴（**第三维**） |
| 气泡 | 可选 | size/气泡/气泡大小/规模/权重 | 编码第 4 维（点的大小） |
| 分组 | 可选 | series/group/系列/分组/渠道/门店/城市/部门 | 颜色区分 |

- **数值列 ≥3**（x/y/z）；若有第 4 个数值列则作气泡大小
- 3 列数值时：若原散点把第 3 列识别为 size，3D 会**让位给 Z**（放弃气泡）——因为 Z 是核心维度
- `label`/`name` 等文本列作点名（tooltip 首行）

## Z 选取优先级

1. 显式 z 别名（列名含 z/高度/深度/利润/评分…）
2. 剩余数值列的第一个（排除 x/y/size）
3. 只有 x/y/size 三列 → **size 转作 Z**，气泡停用

## 投影

真三维透视投影（非 2D 伪 3D）：

- 归一化三轴到 [0,1] 立方体，绕 Z 轴转**方位角**、按**倾角**压扁，Z 作高度
- 点按深度排序绘制（远的先画、近的后画，正确遮挡）
- 地面网格（z=0 平面）+ X/Y/Z 三轴线框辅助定位
- 视图自适应：按立方体 8 个顶点的投影包围盒同时缩放宽高并居中，任何视角下三轴都在画布内；缩放只在此基础上叠加

## 交互

- **拖拽旋转**：改变方位角 + 倾角
- **滚轮缩放**：0.5×–2.4×
- **倾角滑块**：15°–85°
- 复位视角；地面网格/三轴/气泡开关
- 悬浮命中：tooltip 显示点名、分组、三轴值、气泡值；detail 行同步；重叠时取最近（最上层）的点
- 点击图例显隐分组
- 主题切换

## 注意

- 相关系数 **r(x,y)/r(y,z) 仅供参考**，旋转不改变 r；位置关系需旋转后判读
- X/Y/Z 含缺失/非法值时按 0 计并在识别报告警告（位置可能有偏）

## 示例

```bash
python vizscape.py render examples/sample-scatter3d.csv --view scatter3d --theme light --out out/scatter3d-light.html
python vizscape.py inspect examples/sample-scatter3d.csv
```
