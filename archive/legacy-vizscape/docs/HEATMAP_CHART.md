# Virta 热力图（heatmap-basic）输入契约

热力图回答**「密度与模式在哪」**：二维网格上颜色的深浅。双模式自动判定：

| 数据形态 | 模式 | 呈现 |
|---|---|---|
| `x` + `y` + `value` | 矩阵 | 类目 × 类目网格（星期×时段、产品×月份） |
| `date` + `value` | 日历 | GitHub 风格周×星期年图（每日一格） |

## 1. 矩阵模式列契约

| 列 | 别名 | 说明 |
|---|---|---|
| **x** | `x` / `col` / `column` / `列` / `横轴` / `weekday` / `星期` / `时段` | 横轴类目，必填 |
| **y** | `y` / `row` / `行` / `纵轴` / `hour` / `小时` | 纵轴类目，必填 |
| **value** | `value` / `count` / `数量` / `数值` 等全量数值别名 | 必填 |

列名不在别名表时**自动回退**：数值列取 80% 可解析的第一列，x/y 取前两列非数值列。轴排序：全数字按数值升序，否则按首见顺序。

```csv
weekday,hour,visitors
周一,12,88
周一,13,74
```

## 2. 日历模式列契约

| 列 | 别名 | 说明 |
|---|---|---|
| **date** | `date` / `day` / `日期` / `时间` / `time` | 必填，复用甘图全量日期格式 |
| **value** | 同上 | 必填 |

多年数据全部输出，页面顶部「年份」段切换。同日多行**求和合并**。

## 3. 色带

- **◧ 顺序**（默认）：纸面色 → 主色单色 ramp，越深越大。
- **◨ 发散**：负值红、正值主色、0 为界；**仅当数据同时含正负值时可用**，否则按钮禁用。
- 色带条（scalebar）实时标注值域，随主题/配色/色带模式联动。

## 4. 交互

- 悬停格子：tooltip + 明细行（矩阵模式附带**行/列合计与全局占比**）。
- `# 数值标注`：格内写数值（格宽 ≥30px 才写，按底色亮度自动选黑/白字；日历模式禁用）。
- 舒适/紧凑密度；错峰入场动画（矩阵按对角线、日历按周列）。
- 缺值格留空（半透明占位），不参与色带。

## 5. 数据识别报告

- 重复 `(x,y)` 格子求和合并并计数；
- 缺 x/y、数值无法解析的行剔除并计数；
- 网格覆盖率 < 50% 触发稀疏警告；
- 日历模式输出天数/年份/总量/日均/峰值日。

## 6. 命令

```powershell
python vizscape.py render heat.csv --template heatmap-basic --theme light --out out/heat.html
python vizscape.py render steps.csv --view heat --title 每日步数
```
