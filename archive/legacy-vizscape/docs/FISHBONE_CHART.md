# 鱼骨图（fishbone-basic）

把一个问题（鱼头）的原因按大类拆解成鱼刺结构：主骨两侧斜刺 = 原因大类，横枝 = 具体原因，45° 细刺 = 子原因。适用于根因分析、质量复盘（人机料法环测）、头脑风暴结构化。

## 输入契约

| 列 | 别名（不区分大小写/连字符/空格） | 必需 | 说明 |
|---|---|---|---|
| category | cat / dimension / 类别 / 类目 / 维度 / 大骨 / 分类 / 分组 / group / 方面 | ✓（缺失归「未分类」） | 原因大类 |
| cause | reason / 原因 / 小骨 / 因子 / 因素 / 问题点 / 根因 / label / name / 事项 / 原因描述 | ✓ | 具体原因（横枝） |
| sub | subcause / 子原因 / 子因 / 孙骨 / 二级原因 / 细分 | — | 子原因（45° 细刺） |
| owner | owner / 负责人 / 责任人 / 担当 / assignee | — | 负责人（tooltip/明细展示） |

- **鱼头（问题）= 标题**：`--title` 参数，缺省用文件名
- 类别顺序按首见；每类内原因按行序
- 兼容 csv / json / xlsx

## 数据识别与清洗

| 情况 | 行为 |
|---|---|
| 原因为空 | 跳过该行，计入警告 |
| (类别+原因+子原因) 重复 | 合并去重，计入警告 |
| 类别为空 | 归入「未分类」 |
| 类目不均衡（最多 ≥ 3× 最少） | 警告「版面会偏向一侧」，置信降为中 |
| 缺 cause 列 | 报错退出，提示所需列名 |

## 呈现规则

- **主骨**：鱼尾 → 鱼头箭头，2.6px 主线；鱼头 = accent 色圆角 pill（自动收缩字号防超宽）
- **大骨**：64° 斜刺，上下交替排布（第 1/3/5… 类在上，2/4/6… 在下），类名 pill 落在骨尖端
- **小骨**：横枝贴骨，间距 = 行距（舒适 36 / 紧凑 27），文字在枝外侧，文字宽度参与槽位计算防止碰撞
- **孙骨**：45° 细刺 + 10px 小字，挂在横枝 55% 处
- **版面超宽**：整体等比缩放适配容器，右下角标注缩放比例
- **方向**：鱼头向右（默认）/ 向左，整体几何镜像、文字保持正向可读

## 交互

| 控件 | 行为 |
|---|---|
| 方向 | 鱼头向右 ▶（默认）/ ◀ 鱼头向左 |
| 密度 | 舒适（行距 36）/ 紧凑（27） |
| 风格 | 10 套配色（类别用调色板序色，鱼头/hover 用页面 accent） |
| ▶ 重播动画 | 主骨生长（380ms）→ 鱼头 pop → 大骨逐类 100ms 错峰 → 横枝逐条 60ms |
| 图例 | 类别色块 + 原因数，点击显隐整类（布局自动重排） |
| 悬浮 | 横枝/类别 pill 命中；同类因果链高亮（大骨加粗变色），tooltip + 明细行同步 |

## 渲染

```bash
python vizscape.py render examples/sample-fishbone.csv --template fishbone-basic --title 产品漏检率高 --out out/fishbone-light.html
# 或 --view fish 自动映射
```
