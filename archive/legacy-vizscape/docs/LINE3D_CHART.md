# 3D 折线图 输入契约

> 定位：在 2D 折线（一条时间轴看多条线）的基础上，把**各系列沿深度轴排布**，形成真三维的带状折线——旋转后可以看每条线在不同深度的相对位置与整体包络。适合多系列同量纲对比。

## 适用场景

- 12 个月 × 消费/出行/政务 三个业务的月度活跃度
- 多渠道周转量对比（各门店、各区域的月销量趋势）
- 多指标体检趋势（身高/体重/血压的年度在同轴上对比）

不适合：

- 只有单系列 → 普通折线（`--view line`）
- 想看分类构成份额 → 占比/树状（`--view pie` / `--view treemap`）
- 想看两个量的相关性 → 散点（`--view scatter`）
- 想看时间序列 + 目标差距 → 普通折线 + 参考线（line-basic 已覆盖）

## 输入 schema

与 2D 折线完全一致（`to_chart` 复用）：

| 形态 | 结构 | 说明 |
|---|---|---|
| 宽表 | `label/分类列, 数值列1, 数值列2, …` | 每个数值列=一条系列，沿深度轴排布 |
| 长表 | `label, series, value` | 按 series 分组对齐 |
| ECharts JSON | `{xAxis:{data:[…]}, series:[{name, data:[…]}]}` | 原样透传 |
| 单系列 | `label + value` | 一条飘带折线，居中放置 |

- **分类列**：别名同 2D（label/月份/1月…；支持 YYYYMMDD、2024-03、中文季度等）
- **系列列**：别名同 2D（series/group/系列/渠道/门店…，归一化匹配）
- **数值列**：整列解析率 ≥ 80%，X/空值按 0 计并警告
- 所有系列共用同一 Z（高度）刻度，旋转不改变相对高度——可直接比较前后系列

## 视图编码

- **X 轴**（地面轴）：分类 / 时间标签（每项一个槽位；类别过多自动跳画）
- **Y 轴**（地面深度轴）：系列位置（首系列→最远），深度排序绘制保证遮挡正确
- **Z 轴**（垂直）：数值高度（自适应刻度，参考墙上有 0/25/50/75/100% 刻度线）

## 投影与自适应

- 真三维透视投影（非 2D 伪 3D）：绕垂直轴转方位角 + 倾角压扁
- 按立方体 8 个顶点的投影包围盒同时缩放宽高并居中，任何视角下三个轴都在画布内
- 地面网格（每条系列一条行线 + 每分类一条列线）
- 参考墙（最远景的高程网格，直接读数值）

## 交互

- **拖拽旋转**：方位角 + 倾角
- **滚轮缩放**：0.5×–2.4×；倾角滑块 15°–85°
- **飘带填充**：每条系列到地面的投影（可开关）
- **参考墙**：最远景高程网格（可开关）
- **数据点**：顶点圆点开关
- 悬浮命中：高亮顶点 + 铅垂虚线 + tooltip（数值 / 较前期变化 / 占该系列峰值百分比）
- 图例点击显隐系列
- 主题切换：双主题

## 示例

```bash
python vizscape.py render examples/sample-line3d.csv --view line3d --theme light --out out/line3d-light.html
python vizscape.py inspect examples/sample-line3d.csv
python vizscape.py schema line3d
```

auto 推荐不纳入 3D 折线（需显式 `--view line3d`），避免改变现有 line 行为。
