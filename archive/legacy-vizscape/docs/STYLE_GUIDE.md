# bar-basic 视觉样式指南

> 适用范围：`templates/bar-basic/` 的纯静态产物。CLI 仍只负责 `light | dark` 注入；页面内样式切换不改变数据契约。

## 1. 两类可选项

### 配色风格 `palette`

| 值 | 中文名 | 适用场景 | 气质 |
|---|---|---|---|
| `signal` | Signal | 默认、业务汇报、通用评审 | 高辨识、信号色、双主题都清晰 |
| `cinnabar` | 朱砂 | 营销 / 竞品 / 风险评审 | 热、锐、主张强，适合讲故事 |
| `patina` | 铜绿 | 工程、环境、质量、运维 | 沉稳、植物/金属感、低饱和 |
| `blueprint` | 蓝图 | 架构、技术方案、审计 | 冷静、理性、网格与图纸感 |
| `inkwash` | 水墨 | 编辑部、长文、报告封面 | 克制、灰阶、留白优先 |
| `mono` | 单色 | 黑白印刷、无障碍打印 | 信息密度高、无需颜色辨识 |
| `sundown` | 落日 | 发布会、增长复盘、消费类专题 | 暖橙→酒红渐层，热烈有叙事感 |
| `dunhuang` | 敦煌 | 文化/文旅/国潮专题、年报封面 | 石青石绿+赭石金，矿物颜料质感 |
| `aurora` | 极光 | 深色大屏、科技感演示 | 青→紫→品红冷光，暗背景下发光感 |
| `morandi` | 莫兰迪 | 奢侈品、生活方式、轻量周报 | 低饱和灰调，安静高级 |

### 柱体表面 `finish`

| 值 | 中文名 | 说明 |
|---|---|---|
| `gradient` | 渐变 | 默认；轻微纵深，适合通用场景 |
| `flat` | 纯色 | 扁平化、远距离投影清晰 |
| `outline` | 描边 | 透明底 + 彩色描边，适合线框图/蓝图风 |
| `hatch` | 斜纹 | 45° 阴影纹理，适合黑白打印与纹理编码 |
| `glass` | 玻璃 | 高光 + 透明层次，适合发布页/屏幕演示 |
| `papercut` | 纸雕 | 偏移阴影 + 暖调层叠，适合编辑部/专题页 |
| `ribbed` | 竖纹 | 竖向明暗纹理，像金属拉丝/布料沟槽 |
| `dotted` | 点阵 | 柱内点阵，适合印刷风、图表纹理编码 |
| `metal` | 金属 | 横向高光带 + 明暗侧，适合仪表盘主指标 |
| `neon` | 霓虹 | 半透明填充 + 外发光，适合深色大屏 |
| `carve` | 浮雕 | 顶/左高光 + 底/右阴影，像从纸面推出 |

## 2. 形状 `shape`

| 值 | 中文名 | 说明 |
|---|---|---|
| `round` | 圆角 | 默认；最通用，保留伪 3D 支持 |
| `rect` | 直角 | 最硬朗，适合工程/审计感 |
| `pill` | 胶囊 | 全圆角，适合 KPI 数值条 |
| `dome` | 穹顶 | 半圆拱顶，像模块/容器 |
| `taper` | 梯形 | 顶窄底宽，像稳定向上的梁 |
| `skew` | 斜切 | 平行四边形，速度感 |
| `crystal` | 尖顶 | 顶点向上，像钻石/声波 |
| `barrel` | 收腰 | 两侧向内收，鼓囊感 |
| `notch` | 缺口 | 顶部 V 形刻痕，像工业件 |

伪 3D 只在 `round` / `rect` 且模式为 `grouped/stacked/pct` 时可用；其余柱形切换后会自动关闭伪 3D。

## 3. 可访问性约束

- 所有可切换按钮都设置了 `aria-pressed`。
- `mono` + `hatch` 是“无颜色依赖”组合，可用于黑白/色弱场景。
- `outline` / `hatch` 在堆叠数值标签中强制使用 `ink`，避免彩色底上的白字失效。
- 键盘焦点：`:focus-visible` 使用当前 `--acc` 描边。

## 4. 不属于本文件的改动

- 不改数据结构：`labels / series / values`
- 不改 CLI 参数契约：`--theme light|dark` 保持不变
- 不引入 CDN / 外部字体；产物仍需离线可开
- `palette/finish` 不提升为 CLI 参数；样式切换只发生在页面内，不改 Python 解析/渲染链路
