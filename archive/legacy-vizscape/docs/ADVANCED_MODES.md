# bar-basic 高级模式说明

> 说明页面内新增的 `pct` 与 `pareto` 两种模式；它们不改变 CSV/JSON/XLSX 输入契约。

## 100% 堆叠（`pct`）

- 作用：看每个分类内部的结构占比，不被分类总量大小干扰
- 计算：每个分类总量为 100，各 series 按占比分配高度
- 值标签：显示 `%`，悬浮仍显示原始数值
- 适用：渠道构成、预算构成、投诉原因结构、市场份额

## Pareto（`pareto`）

- 作用：回答“少数原因是否贡献了大部分结果”
- 计算：按分类可见 series 小计降序排列；绘制各分类柱子 + 累计占比折线；右轴 0–100%；含 80% 参考线
- 多系列：柱高使用可见 series 小计；隐藏图例后 Pareto 会同步重算
- 值标签：柱顶显示分类小计；折线点显示累计 `%`
- 适用：故障归因、缺陷 Pareto、工单原因、竞品差距拆解

## 设计取舍

- Pareto 不做 3D：3D 会破坏“降序 + 累计线”的判读节奏
- 100%堆叠不要求数据清洗为百分比：原始数值进入，占比在渲染层计算
- CLI 仍然只暴露 `light|dark`；模式切换发生在产物页面内

## 瀑布图（`waterfall`）

- 作用：把一组增减贡献拆成“从哪来 → 到哪去”，适合预算偏差、利润桥、成本结构变动
- 计算：按输入行顺序累计；`delta` 行绘制相邻区间，`absolute` 行从 0 绘制为锚点/小计/总计
- 连线：相邻柱之间画虚线，表示当前水位传递
- 颜色：单系列或锚点柱使用 ink 锚点；多系列增减按 series 配色叠加为贡献分量；正/负贡献不要求同号
- 多系列：同一阶段内按可见 series 顺序逐段累计，tooltip 会同时显示“本段贡献”和“本步合计”
- 约束：至少一个可见系列；没有可见系列时为空状态
- 输入标记：可选 `类型` 列（别名 `type/kind/marker/阶段类型/类型/行类型`），值为 `delta|增减|变动|差额` 或 `absolute|subtotal|total|小计|合计|总计|累计`
- 未知标记按 delta 处理，同一分类多种行类型按首次出现绘制，并在数据识别报告中警告

## 负值与零基线

- `grouped` / `stacked` 支持正负值：纵轴自动扩展到正负区间，零基线加粗显示
- `pareto` / `pct` 只适用于非负数值：一旦当前可见 series 含负值，这两个按钮会被禁用；若此时正处于这两个模式，会自动回到 grouped
- 混合正负的 `stacked`：正项向上累计、负项向下累计，不会把负值偷偷当 0
- 数据识别报告会单独统计负值数量，并说明 Pareto / 100%堆叠为何不可用
