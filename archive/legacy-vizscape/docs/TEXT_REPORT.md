# 文本 / Markdown 指标识别规则

> 批次 B/C。维护：解析与规则在 `docmd.py`，渲染在 `docrender.py`。目的：把「看起来有数字的句子」变成可复核的指标，每个指标都带**识别方式**和**来源句**；识别不了就明说，不静默编造。

## 1. 输入与编码

| 项 | 规则 |
|---|---|
| 扩展名 | `.md` / `.txt`（`DOC_SUFFIXES`），其他扩展名直接报错退出 |
| 编码 | 依次尝试 `utf-8-sig`（容 BOM）→ `gb18030` → `utf-8` 容错替换 |
| 换行 | `\r\n` / `\r` 统一为 `\n` |

## 2. Markdown 块解析

支持：`#` 标题（1–6 级）、段落（软换行合并，中文不加空格、西文加空格）、无序/有序列表（含嵌套，缩进 2 空格一层）、表格（`|` + 分隔行，识别 `:---` / `---:` / `:---:` 对齐）、`>` 引用（多段）、围栏代码块（``` / ~~~ + 语言标记）、`---` 分割线、行内 `code` / `**bold**` / `*em*` / `~~del~~` / `[链接](url)` / `![图片](url)`。

- **第一个 H1 视为文档标题**，不再进正文和目录
- 标题生成 slug 锚点（去标点、中文保留、重名加 `-2`）
- **章节** = 正文里层级最浅的标题（通常是 H2）；`章节篇幅` 按章节内非空字符统计

## 3. 指标三路抽取

按句子从句切分（`，；;。！？!?、` 与非数字旁的逗号）后匹配：

| 方式 | 形态 | 示例 | 说明 |
|---|---|---|---|
| `explicit` 显式标签 | `标签：数值单位` | `营收：12.5 亿元` | 标签 2–24 字，含中文/字母开头 |
| `inferred` 推断 | `标签 (为/达到/约/…) 数值单位` | `订单量达到 1,200 万单` | 无冒号，靠动词与位置推断，**必须标出来复核** |
| `table` 表格 | 行名 + 列名 + 数值单元格 | `线上商城 · 占比 = 54%` | 标签 = `行名 · 列名`，只取非首列 |

### 可解析数值形态

| 输入 | 结果 |
|---|---|
| `1,200` / `1，200` | `1200`（千分位、中文逗号） |
| `¥1,200` `$980` `€76` `￥88` | 剥离货币符号 |
| `(1,234)` | `-1234`（括号负数） |
| `+12` / `-45.5` / `8.5%` | 保留符号；百分号**保留原刻度**（8.5 → 8.5，不转 0.085） |

### 单位表

`个百分点 百分点 亿元 万元 万单 万人 个月 小时 分钟 天 % ‰ ms 秒 GB MB TB KB pt 倍 亿 万 元 单 人 次 个 家 台 x`

### 过滤规则（防噪声）

- 标签 < 2 字、命中停用词（`注意/说明/备注/结论/提示/示例/版本/时间/日期/来源/更新/附注/注/例如/截至`）、标签以数字结尾 → 丢弃
- **纯年份不当指标**：`2026` 且无单位 → 丢弃（否则每句话的日期都会变成指标）
- 同 `(标签, 数值, 单位, 章节)` 去重
- 一个从句里 `explicit` 命中后，该区间挖空再跑 `inferred`，避免同一数字被抽两次

## 4. 文档识别报告

与表格的「数据识别报告」同款样式，字段：

- **chips**：模式（`markdown` / `text`）、标题、段落、表格、列表、代码块、图片（未加载数）、指标、推断
- **warnings**（有则左侧红条 + 中/低置信）：
  - 文档为空
  - 无 `#` 标题 → 目录为空
  - 无可用指标
  - N 个推断指标需复核
  - N 个图片未加载（离线产物）
  - N 个链接协议不安全（`javascript:` 等）→ 去链保文
  - 原文含 HTML 标签 → 按纯文本转义，不生效
- **confidence**：无块或无指标 = `low`；无标题或含推断 = `medium`；否则 = `high`

## 5. 产物约定

- 离线单文件：**图片不加载**，显示 `🖼 名称 · 离线未加载` 占位；外链仅放行 `http(s)/mailto/#/相对路径`，其余降级为纯文本
- KPI 卡片最多 8 个，排序 `explicit > inferred > table`；推断项带「推断」标签与灰顶条；`%` 指标带比例条
- KPI 与指标明细的「来源章节 / 来源句」都是锚点链接，点一下跳到正文对应章节
- 正文、目录、指标明细全部 HTML 转义，数据里的 `<script>` 只显示为文本

## 6. 已知取舍

- **推断识别宁多标不漏标**：`毛利率仅 18%`、`库存周转天数 45 天` 这类无冒号句会被抽出来，代价是可能抽到非指标的数字（如「较上季度下降 1.4%」的比较句）。所以一律打 `inferred` 标签 + 来源句，交给读图的人复核。
- **表格只取数值单元格**：`渠道` 这类文本列不会进指标；表头本身也不进指标。
- **章节篇幅按最浅标题切分**：H3 子章节不单独成条，字数并入所属 H2。
- **不跨句推断**：标签和数值必须在同一从句内，避免把两句话的词拼成假指标。

## 7. 呈现层增强（模板运行时，不改解析）

以下能力全部在 `templates/report-basic/template.html` 内完成，`docmd.py` / `docrender.py` 输出结构不变：

- **代码块卡片化**：`pre.code` 在页面加载时升级为 `.codeblock` —— 深色头栏（红黄绿三点 + 语言标签）+ **行号**（CSS 计数器）+ **轻量语法高亮**（行级正则：注释 / 字符串 / 数字 / 关键字，关键字表覆盖 JS/Python/SQL 常用词；所有片段重新转义，XSS 安全）+ **⇋ 换行**（软换行开关）+ **⧉ 复制**（复制原文而非高亮后 HTML，clipboard API 降级 textarea）
- **标题悬浮锚点**：H2/H3/H4 悬浮出现 `#`，点击复制小节深链
- **表格**：外框圆角 + 阴影 + 行 hover 高亮 + 数字列 `tabular-nums`；指标明细表超 540px 时内部滚动、表头吸顶
- **排版控制条**：字号 小 / 标准 / 大（14 / 15 / 16.5px）+ ⇤⇥ 宽版（正文 760 → 940px）
- **格式细节**：引用块加大号 `"` 饰标与底色、行内代码描边胶囊、链接改下划线为底部描边 + hover 底色、`hr` 渲染为 `✦ ✦ ✦`、列表 marker 用主题色、`::selection` 主题色
