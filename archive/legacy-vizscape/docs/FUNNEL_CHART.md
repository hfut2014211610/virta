# 转化漏斗 输入契约

> 定位：只回答「一条流程逐级递减多少、哪一步掉得最狠、从首级一路还剩多少」。不看时间波动、不看份额构成、不看两个量的关系。

## 适用场景

- 注册 → 激活 → 下单 → 复购
- 投递 → 初筛 → 面试 → 录用
- 线索 → 商机 → 报价 → 成交
- 曝光 → 点击 → 加购 → 下单

不适合：

- 阶段是时间点、想看随时间波动 → 折线图（`--view line`）
- 想看各阶段占整体份额 → 占比图（`--view pie`）
- 有正有负的增减 → 柱状图（`--view bar`，支持瀑布）
- 指标离目标差多少 → 子弹图（`--view bullet`）

## 输入 schema

| 列 | 必需 | 别名 |
|---|---|---|
| 阶段 | 是 | label, name, category, x, 分类, 类别, 标签, 名称, 指标, 阶段 |
| 数值 | 是 | value, count, amount, y, 数值, 数量, 金额, 销量, 营收, 人数 |

支持 `阶段 + 数值` 单系列、`阶段 + 系列 + 数值` 长表、宽表多数值列（按各系列小计）、ECharts JSON。

## 阶段顺序

**按行序**（表格行出现顺序），不是时间序列。首行 = 漏斗顶部（基数最大）。

- 每级宽度 = 该阶段数值 / 首级数值
- 逐级转化率 = 当前级 / 上一级
- 累计留存率 = 当前级 / 首级
- 流失 = 上一级 − 当前级

## 切片规则

1. **负值剔除**并在识别报告警告（漏斗无法表示负宽度）
2. **0 值剔除**（后续转化率不可计算）
3. **顺序回升警告**：后一阶段数值大于前一阶段时提示确认（漏斗通常单调递减，但回升是合法的，仅提醒核对顺序）
4. 首行视为 100% 基准；若首行不是最大值，建议按数量降序排列输入

## 字段识别

- 数值列：整列解析率 ≥ 80%
- 文本列：解析率 < 80%
- 多系列时每个阶段取各系列小计（与柱状图 Pareto 排序口径一致）

## 交互

- 悬浮命中：梯形高亮、tooltip 显示「数值 · 累计留存 · 逐级转化 · 流失」
- 点击图例显隐阶段（隐藏后宽度按剩余最大值重算）
- 形态切换：居中漏斗 / 左对齐漏斗
- 转化率标注开关；最大流失高亮开关
- 主题切换

## 示例

```bash
python vizscape.py render examples/sample-funnel.csv --view funnel --theme light --out out/funnel-light.html
python vizscape.py inspect examples/sample-funnel.csv
```
