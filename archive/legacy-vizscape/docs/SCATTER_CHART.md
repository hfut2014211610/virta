# 散点 / 相关性气泡图 输入契约

> 定位：只回答「两个数值量之间有没有关系、是不是线性、谁是离群点」。不做趋势预测、不做分类排行、不做构成占比。

## 适用场景

- 投放成本 vs 转化数、广告预算 vs 销售额
- 客单价 vs 复购率、加载耗时 vs 跳出率
- 缺陷数 vs 处理时长、测试用例数 vs 漏测率

不适合：

- 有顺序、想看走势 → 用折线图（`--view line`）
- 想看分类间数值高低 → 用柱状图（`--view bar`）
- 想看目标差 → 用子弹图（`--view bullet`）

## 输入 schema

| 列 | 必需 | 别名 |
|---|---|---|
| X 值 | 是 | x, x值, 横轴, 自变量, 成本, 投入, 投放入 |
| Y 值 | 是 | y, y值, 纵轴, 因变量, 转化, 收益, 产出 |
| 分类列 | 否 | label, name, category, 分类, 类别, 标签, 名称, 指标 |
| 分组列 | 否 | series, group, 系列, 分组, 渠道, 门店, 城市, 部门 |
| 气泡大小 | 否 | size, 气泡, 气泡大小, 规模, 权重 |

### 三种输入形态

| 形态 | 说明 | 例子 |
|---|---|---|
| 显式 x/y | 列名命中 X/Y 别名 | `投放入(万元), 转化数(单)` |
| 宽表前两数值列 | 无 x/y 别名时，前两数值列 = x/y，文本列作点名 | `城市, 广告投入, 销售额` |
| ECharts | `series[].data` 为 `[x,y]` 或 `[x,y,size]` | 无 xAxis 的散点 JSON |

## 分组规则

- 有**另一个文本列**命中系列别名（如 `渠道`、`月份`）→ 按它分组着色 + 图例开关
- 系列列**同时是 label**（如只有 `渠道,投放入,转化数`）→ 渠道既作分组又作点名会打架；
  label 优先落到另一个文本列（如 `月份`），若只有一个文本列则退为单组（渠道作点名，全部点同色）
- 宽表无系列列 → 全部点一组

## 字段识别

- **数值列**：整列解析率 ≥ 80% 视为数值列
- **文本列**：解析率 < 80%
- **x/y**：命中 X/Y 别名，或宽表前两数值列
- **size**：命中 size 别名；有值时**自动启用**「按 size 列」气泡
- label 别名不含「名称/指标」——它们易与渠道/城市这类系列列冲突，系列列优先当分组

## 缺省与边界

- 缺失/非法数值按 0 计，进数据识别报告（低置信）
- 负值：X/Y 自动下探到负区间，零线单独加深
- 相关系数 r：`n >= 2` 且 X/Y 方差都 > 0 时计算 Pearson r；否则显示 `—`
- 拟合线：一次线性最小二乘，只画 X 范围内的段落；点云非线性时（如幂律）请开 log 轴

## 交互

- 悬浮命中：显示点名、分组、X、Y、size
- 拖拽框选：刷选区域，只统计选中点的 Y 均值；按住 alt 拖拽为减选
- 双击或「重置刷选」：清除刷选
- 趋势线开关、log X / log Y、气泡「统一 / 按 size 列」、主题切换

## 示例

```bash
python vizscape.py render examples/sample-scatter.csv --view scatter --theme light --out out/scatter-light.html
python vizscape.py inspect examples/sample-scatter.csv   # 会打印 ALSO --view scatter 提示
```
