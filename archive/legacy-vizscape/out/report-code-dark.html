一、背景

现有日批任务耗时 3.4 小时，超出窗口 22%。失败重试率：8.6%。

  • 增量同步覆盖 14 张表
  • 峰值内存 62 GB
  • 平均延迟：38 分钟

二、改造点

2.1 抽取层

把全量拉取改为 binlog 订阅，核心代码如下：

python
# 增量游标：按 updated_at 推进，幂等
def fetch_delta(cursor, table, batch=5000):
    sql = f"SELECT * FROM {table} WHERE updated_at > ? ORDER BY updated_at LIMIT {batch}"
    rows = cursor.execute(sql, [last_watermark()]).fetchall()
    for row in rows:  # 逐行推进游标
        yield row
    return len(rows) == batch

2.2 计算层

sql
-- 会话化：30 分钟间隔切分
SELECT user_id,
       session_id,
       COUNT(*) AS events,
       SUM(amount) AS gmv
FROM events
WHERE dt = '2026-11-03'
GROUP BY user_id, session_id
ORDER BY gmv DESC
LIMIT 100;
