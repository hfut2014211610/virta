# 占比图（饼 / 环形）输入契约

> 定位：只回答「一个分类维度占整体多少份额，谁是主力、哪些是小头」。不看时间趋势、不看正负对比、不看两个量的关系。

## 适用场景

- 渠道 / 品类 / 地区构成（线上 vs 门店 vs 第三方）
- 预算或成本分配（人力 / 采购 / 营销）
- 流量来源分布、投诉类型占比

不适合：

- 有时间顺序、想看走势 → 折线图（`--view line`）
- 正负有正有负、想看增减 → 柱状图（`--view bar`，支持瀑布）
- 想看两个量的关系 → 散点图（`--view scatter`）
- 指标离目标差多少 → 子弹图（`--view bullet`）

## 输入 schema

| 列 | 必需 | 别名 |
|---|---|---|
| 分类 | 是 | label, name, category, x, 分类, 类别, 标签, 名称, 指标 |
| 数值 | 是 | value, count, amount, y, 数值, 数量, 金额, 销量, 营收 |

支持 `label + value` 单系列、`label + series + value` 长表、宽表多数值列（每个数值列一系列，按各系列小计求和）、ECharts JSON。

## 切片规则

1. **每个分类的值** = 各可见系列在该分类的求和（单系列即该列本身）
2. **按占比降序排列**，自 12 点顺时针绘制
3. **负值剔除**并在识别报告警告（饼图无法表示负份额，请改用柱状图看正负对比）
4. **0 值剔除**（占比不可见）
5. **尾部小份额并入「其他」**：降序后占比 < 3% 的连续尾部合并为「其他（N 项）」，避免图上碎扇区挤成一团
6. 总和 ≤ 0 时直接报错退出（提示改用柱状图）

## 字段识别

- 数值列：整列解析率 ≥ 80%
- 文本列：解析率 < 80%
- 多系列时每个分类取各系列小计（与柱状图 Pareto 排序口径一致）

## 交互

- 悬浮命中：扇区外扩高亮、tooltip 显示「数值 · 占比」、中心切换为该项占比与名称、侧栏显示占比与排名
- 点击扇区或图例：显隐该项（隐藏后其余按剩余总量重算占比）
- 环形 / 实心切换；环上数值标注开关（小扇区不标注避免重叠）
- 主题切换

## 示例

```bash
python vizscape.py render examples/sample.csv --view pie --theme light --out out/pie-light.html
python vizscape.py render examples/sample-multi.csv --view pie --json   # 多系列：按各系列小计
```
