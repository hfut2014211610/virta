# 雷达图 输入契约

> 定位：只回答「多个对象在多个维度上谁强谁弱、谁更均衡」。不看份额占比、不看趋势、不看两量关系。

## 适用场景

- 能力雷达：产品 A/B/C 在易用性/性能/安全/成本/生态的对比
- 竞品对比：多维评分（功能、体验、价格、服务…）
- 多指标体检：团队/方案在需求/设计/开发/测试/交付的强弱

不适合：

- 想看各维占整体份额 → 占比图（`--view pie`）
- 想看随时间变化 → 折线图（`--view line`）
- 只有 1–2 个维度 → 用分组柱状图（`--view bar`）
- 两个量的相关性 → 散点图（`--view scatter`）

## 输入 schema

雷达是**多轴 × 多对比项**结构：

| 输入形态 | 结构 | 说明 |
|---|---|---|
| 宽表（推荐） | `维度, 对比项1, 对比项2, …` | 每行=一个维度轴（≥3），每个数值列=一个对比项 |
| 长表 | `维度, 对比项, 数值` | 同一维度多行，按对比项对齐成系列 |
| ECharts JSON | `{xAxis:{data:[轴]}, series:[{name, data:[值]}]}` | 同宽表语义 |

- **轴数**：≥3（少于 3 报错，雷达无意义）
- **对比项数**：建议 ≤8（图例可读；模板顶点数值在 >6 项时自动隐藏避免重叠）
- **别名**：轴列同 bar 的 label 别名（`label/name/category/x/维度/分类/类别` 等），数值列同 bar 的 value 别名

## 归一化

各轴**量纲常不同**（如收益 0–100、周期 0–10），直接同图叠加会失真。雷达按轴归一化：

- 每轴按该轴**最大值 = 1** 映射到 0..1
- 轴含负值时按该轴 **min..max** 平移到 0..1（并在识别报告警告：占比仅在该轴内可比）
- 轴刻度环显示 0.25/0.5/0.75/1.0；轴标签旁标 `max <原始最大值>`

**覆盖面积**（多边形面积）用于衡量"均衡且大"：面积越大、形状越饱满 = 综合占优。面积只在**同图内**可比。

## 字段识别

- 数值列：整列解析率 ≥ 80%
- 文本列：解析率 < 80%
- 长表形态：当宽表把不同对比项误并成单系列时，若原表有「维度 + 对比项」两个文本列 + 一个数值列，自动按 (维度, 对比项) 分组展开成多系列

## 切片 / 警告

1. **轴含负值**：警告"按该轴最小值平移，占比仅在该轴内可比"
2. **轴数 < 3**：直接报错（`✗ 雷达图至少需要 3 个轴`）
3. 继承 bar 的缺失/非法/负值等基础识别警告

## 交互

- 悬浮命中：多边形高亮、tooltip 列出各轴**原始值 + 归一值(%)**、覆盖面积、均分
- detail 行：领先项 / 覆盖面积 / 最强轴 / 最弱轴 / 悬停提示
- 填充/描边切换、网格与轴开关、轴刻度环开关、顶点数值开关
- 点击图例显隐对比项
- 主题切换

## 示例

```bash
python vizscape.py render examples/sample-radar.csv --view radar --theme light --out out/radar-light.html
python vizscape.py inspect examples/sample-radar.csv
```

auto 推荐不纳入雷达（需显式 `--view radar`），避免改变现有 bar/line 行为。
