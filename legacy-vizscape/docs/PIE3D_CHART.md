# 3D 分层饼图 输入契约

> 定位：在 2D 占比饼的基础上，把**多个分组沿深度轴分层**，每层看该分组内部的份额构成。同一类别跨层同色、同角度——**面积/角度判读不受透视影响**，这是它和传统"透视挤压式 3D 饼"的本质区别。

## 适用场景

- 4 个季度 × 5 个品类：看各季度品类占比变化 + 总量
- 各区域 × 客户渠道：同色对齐横向比较渠道占比
- 单层（label+value）：厚环形图，带 3D 呈现感但不失真

不适合：

- 只有一个分组、一个维度 → 普通饼图（`--view pie`）
- 想看层级路径上的占比 → 旭日图（`--view sunburst`）
- 想看两个量的相关 → 散点（`--view scatter`）
- 类别差异巨大、小份额看不清 → 柱状图（`--view bar`）

## 输入 schema

与树状图同模式（treemap 的列识别复用）：

| 列 | 必需 | 别名 | 说明 |
|---|---|---|---|
| 标签 | 是 | label/name/category/分类/类别/标签/名称 | 扇区 = 该层的占比 |
| 数值 | 是 | value/count/amount/数值/数量/金额 | 每层按此值求和取占比（解析率 ≥ 80%） |
| 分组 | 可选 | group/大区/区域/季度/分组（别名含季度/区域等） | 有分组=多层环；无=单层厚环 |

- 文本列 ≥ 2 时按**基数规则**分配（唯一值少的当分层，多的当标签）
- ECharts JSON 不支持（请先展开成 CSV/Excel）
- **分层顺序**：按各层总值降序（最大层在底层）——视觉稳定、符合阅读顺序

## 层内规则

- 每层占比降序（色序：总值最大的类别取调色板首位）
- 每层内占比 < 3% 的扇区并入「其他（n 项）」（各层独立判定）

## 投影与判读

- 真三维透视投影（非 2D 伪 3D）：绕垂直轴转方位角 + 倾角压扁
- 按立方体 8 个顶点的投影包围盒同时缩放宽高并居中，任意视角下三个轴都在画布内
- 各层**半径相同、角度一致**：越大的比例扇张越宽——不像挤压式 3D 饼那样扭曲占比判断
- 地面网格（单层时显示完整的圆径参考）
- 层标签为固定左列（任何视角不重叠、不出界）
- 扇区标签只标注**背向顶面**的扇区（正面扇区标签会压在柱面上）

## 交互

- **拖拽旋转**：方位角 + 倾角；**滚轮缩放**（0.5×–2.4×）；倾角滑块 15°–85°
- **层标签 / 扇区标签**：开关
- 层按总值降序绘制（最大层在底层）
- 悬浮命中：分层/类别/数值/层内占比/整体占比
- 图例显隐类别（全部隐藏时提示"没有可见类别"）
- 主题切换：双主题

## 示例

```bash
# 多层（季度 × 品类）
python vizscape.py render examples/sample-pie3d.csv --view pie3d --theme light --out out/pie3d-light.html
# 单层厚环
python vizscape.py render examples/sample-pie3d-1d.csv --view pie3d --theme light --out out/pie3d-1d-light.html
python vizscape.py inspect examples/sample-pie3d.csv
python vizscape.py schema pie3d
```

auto 推荐不纳入 3D 饼（需显式 `--view pie3d`），避免改变现有 pie 行为。
