# 甘特图 输入契约

> 定位：只回答「任务排在什么时间、谁在谁前面、谁卡着谁、进度到哪了」。不看数值构成、不看趋势波动。

## 适用场景

- 项目计划 / 版本排期 / 活动筹备
- 跨团队依赖梳理（谁的输出是谁的输入）
- 里程碑节点跟踪

不适合：

- 想看数值随时间的波动 → 折线图（`--view line`）
- 想看各阶段转化 → 漏斗图（`--view funnel`）
- 任务无时间概念、只有先后 → 不是甘特图的领域

## 输入 schema

| 列 | 必需 | 别名 |
|---|---|---|
| 任务 | 是 | task, 任务, 事项, 工作, 工作项, 活动, label, name, 名称 |
| 开始 | 是 | start, begin, startdate, 开始, 开始日期, 开始时间, 启动 |
| 结束 | 二选一 | end, finish, enddate, due, deadline, 结束, 结束日期, 截止日期, 完成日期 |
| 工期 | 二选一 | duration, days, dur, 工期, 时长, 天数 |
| 泳道 | 否 | phase, lane, swimlane, module, 阶段, 分组, 模块, 泳道, 部门, group, 项目 |
| 进度 | 否 | progress, pct, percent, 进度, 完成度, 完成率（0~1 或 0~100% 均可） |
| 状态 | 否 | status, state, 状态 |
| 负责人 | 否 | owner, assignee, 负责人, 成员, 责任人 |
| 依赖 | 否 | deps, depends, dependson, predecessor, predecessors, 依赖, 前置, 前置任务, 前置依赖 |
| 类型 | 否 | type / 类型，值为 milestone / 里程碑 / 节点 时强制按里程碑处理 |

- `结束` 与 `工期` 都缺 → 该任务按 **里程碑 ◆** 处理
- `结束` 与 `工期` 都有 → 结束优先
- 状态词表：完成/已完成/done、进行中/doing/wip、延期/滞后/风险/阻塞/delayed/blocked、未开始/待办/todo/planned；无法识别按普通任务显示并计数警告
- 依赖值：任务名或 1-based 行号，多个用 `; , 、 | /` 分隔；悬空依赖与自引用忽略并警告

## 日期解析

支持格式（开始/结束列通用）：

| 输入 | 示例 |
|---|---|
| 标准日期 | `2026-03-02` `2026/3/5` `2026.03.25` `2026年3月30日` |
| 紧凑日期 | `20260302` |
| 月份 | `2026-03`（按月初） |
| 年份 | `2026`（按年初） |
| ISO 时间 | `2026-03-02T10:30:00`（取日期部分） |
| Excel 单元格 | datetime 类型直接读取 |
| epoch 时间戳 | 秒（≥1e9）/ 毫秒（≥1e12） |
| 相对天数 | `0` `5` `19`（纯数字列） |

**混合模式**：只要存在真实日期，纯数字按「最早日期 + N 天」对齐并警告；全部为纯数字则时间轴显示 `D0 / D1 …`，周末底纹与今日线自动禁用（按钮置灰）。

## 清洗规则（全部计入数据识别报告）

1. 开始时间缺失或无法解析 → **整行跳过**并警告
2. 结束早于开始 → **自动对调**并警告
3. 进度越界（<0 或 >100%）→ 钳制到 0~100% 并警告
4. 状态无法识别 → 按普通任务显示并警告
5. 悬空依赖 / 自引用 → 忽略并警告
6. 任务名重复 → 依赖连线按首个同名任务解析并警告
7. 开始 == 结束 → 自动转里程碑 ◆

## 呈现规则（时间轴视图）

- **行结构**：分组头（加粗大写标签 + 斑马底带）→ 该组任务行；分组顺序按首见（状态分组按 延期→进行中→未开始→完成→常规），图例点击显隐整组
- **时间轴**：刻度步长自适应（日/周/月/季/年），随可用宽度加密或变疏
- **横条**：圆角渐变条，左端=开始、右端=结束，右侧标注工期（Nd）；条内深色填充=进度，宽条内嵌百分比
- **状态语义**：延期=红描边（hover 加粗）、完成=降透明 55%、未开始=虚线框+30% 填充
- **里程碑 ◆**：菱形 + 日期标注（靠右缘自动翻转到左侧防止裁切）
- **依赖连线**：前置任务右端 → 当前任务左端的肘形贝塞尔曲线 + 箭头；悬停任一任务时其相关链路高亮
- **周末底纹**：仅真实日期模式可用，列宽 <8px 时自动不画（避免糊成一片）
- **今日线**：今天落在项目跨度内才显示（虚线 + 标签徽章）

## 日历模式

月历网格视图（仅真实日期数据可用，相对天数数据按钮置灰）：

- 周一起始，日号在格子左上；非当月日期淡显；周末列底纹、今日格描边（随开关）
- 任务条跨日铺排：周视图内贪心分配 lane（舒适 3 / 紧凑 4 条），超出折叠为「+N 更多」
- 跨周任务：在周界处截断，延续段为直角端；本周内起止端为圆角
- 里程碑 ◆ 落格在对应日列；进度内嵌、状态描边/降透明/虚线框语义与时间轴一致
- 月份导航：◀ ▶ 在项目首末月之间翻页（到界自动禁用），「◎ 项目起点」一键回到首月
- 依赖连线为时间轴视图专属，日历模式不画

## 分组模式

| 分组 | 行结构 | 图例 |
|---|---|---|
| ▦ 泳道（默认） | 按 `group` 列分组 | 泳道色块（调色板序色） |
| ◉ 状态 | 按 延期/进行中/未开始/完成/常规 分组 | 状态语义色 |
| ♟ 负责人 | 按 `owner` 列分组，空值为「未分配」 | 调色板序色 |
| — 平铺 | 不分组，全部任务按行序铺开 | 图例隐藏 |

分组与「着色」是两个独立维度：例如按状态分组 + 按泳道着色，可以同时看到状态结构和泳道归属。

## 交互

| 控件 | 行为 |
|---|---|
| 视图 | ▤ 时间轴（默认）/ ▦ 日历；相对天数数据时日历禁用 |
| 分组 | 泳道 / 状态 / 负责人 / 平铺 |
| 密度 | 舒适 / 紧凑（日历模式影响 lane 高度与每周最大条数） |
| 着色 | ▦ 按泳道（默认）/ ◉ 按状态 |
| 周末底纹 / 依赖连线 / 今日线 / 进度 | 独立开关；无真实日期或今日不在跨度内时对应按钮禁用 |
| ▶ 重播动画 | 时间轴任务行 40ms 错峰；日历按周 70ms 错峰淡入 |
| 图例 | 分组色块 + 任务数，点击显隐该分组（两视图通用） |
| 悬浮 | 时间轴整行命中 / 日历按条命中，tooltip 显示工期/进度/状态/负责人/前置 |
| 明细行 | 悬停任务时卡片底部同步完整信息 |

## 配色

10 套调色板 × 浅/深双主题，泳道按序取色 8 循环。状态着色模式下：完成=绿、进行中=蓝、延期=红（`--neg`）、未开始=灰。
