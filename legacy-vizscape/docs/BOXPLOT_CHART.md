# Virta 箱线图（boxplot-basic）输入契约

箱线图回答**「数据分布长什么样」**：中位数、四分位、离散度、离群点，一图五数。

## 1. 双输入形态（自动判定）

**A. 原始观测**（有 `value` 列时）：

| 列 | 别名 | 说明 |
|---|---|---|
| **group** | `group` / `category` / `类别` / `组` / `产线` / `批次` | 缺省取第一列 |
| **value** | 全量数值别名 | 每行一个观测值，组内聚合 |

```csv
line,deviation
A 线,0.32
A 线,-0.85
```

**B. 汇总直绘**（有 `q1`+`median`+`q3` 列时优先）：

| 列 | 别名 |
|---|---|
| q1 / median / q3 | `q1`/`下四分位`/`p25`、`median`/`中位数`/`p50`、`q3`/`上四分位`/`p75` |
| min / max | 可选；缺省时须线端点以 Q1/Q3 代替并警告 |

## 2. 统计规则

- 分位数用 **type-7 线性插值**（与 numpy 默认一致）；
- 须线延伸至 **Q1−1.5·IQR ~ Q3+1.5·IQR 边界内**的最值；界外值为**离群点**（空心圆）；
- 均值以 ◆ 红色标记，与中位数对比可判断偏态（明细行自动给出「左偏/右偏/对称」）；
- 组内样本 **n<5 警告**（五数不稳定）；
- 原始模式下 ≤2000 个观测值传入前端用于 jitter 散点叠加。

## 3. 交互

- 方向：▤ 垂直 / ▥ 水平；排序：首见 / 中位数升降；
- `∴ 原始散点`：jitter 抖动叠加（确定性伪随机，重绘不闪；汇总模式自动禁用）；
- 悬停分组：tooltip 完整五数 + IQR + 离群计数。

## 4. 命令

```powershell
python vizscape.py render qc.csv --view box --theme light --out out/box.html
```
