# Virta 旭日图（sunburst-basic）输入契约

旭日图回答**「总量沿层级路径怎么分」**：内圈是第一层，逐层向外展开，弧长 ∝ 数值。与 treemap 互补——treemap 看面积，sunburst 看层级路径。

## 1. 输入形态（自动判定）

| 列 | 说明 |
|---|---|
| **层级列** | 所有非数值列按**列顺序**作为层级路径，≤4 层（如 `dept / category / item`） |
| **value** | 最后一个数值列，叶子聚合；**父级值 = 子树之和**，无需自备汇总行 |

```csv
dept,category,item,amount
研发,人力,工程师薪酬,5200
研发,人力,外包费用,800
```

- 空层级单元格自动跳过该层（路径压缩，不断链）；
- 同名兄弟自动合并求和；
- 负值/非法值剔除并计入数据识别报告。

## 2. 视觉规则

- 弧长 ∝ 当前视图总量中的占比；环带宽度均分可用半径；
- 第一层取调色板色，**子级色 = 父色向纸面淡化 0.18/层**（明度阶梯，层级一眼可辨）；
- 弧上标签仅在扇区跨距 >0.16 rad 且环厚 >22px 时绘制，过小扇区自动省略；
- 占比 <0.5% 的不可读扇区计入识别报告。

## 3. 交互

- **点击扇区下钻**到该子树，**点击中心圆返回上级**，面包屑可跳任意层；
- 悬停高亮祖先链（其他弧淡化），tooltip 显示路径 + 值 + **占当前视图 / 占全局双占比**；
- `✎ 弧上标签` 开关；`▶ 重播动画`（径向扫入 640ms）；
- 10 套配色风格 + 双主题。

## 4. 命令

```powershell
python vizscape.py render spend.csv --view sunburst --theme light --out out/sun.html
```
